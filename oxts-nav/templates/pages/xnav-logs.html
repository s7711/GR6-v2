The xNAV's own raw logs, newest first; a new one starts at every power-on or reset. Each is named by its start time, in UTC: the xNAV has no clock battery, so each log is mobile.rd (not listed) until GNSS time arrives, about a minute after the reset. Downloads stream straight from the xNAV, so a reset part-way through cuts the download short, and the newest file is still being written. The badge is the u-blox firmware recorded at the start of each file.
