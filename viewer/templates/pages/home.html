Every service's own data/logs/ folder, in one place — see viewer-prd.md. Pick a folder, tick file(s); anything from another folder whose time range overlaps your pick shows up under "Suggested" so runs that happened together are easy to find. Tick quantities per file (each file gets its own tab), then Load. The chart's x-axis is seconds since the earliest loaded file's own start (fixed for the whole loaded set, not per file), so files covering the same real event stay aligned — unless you pick one selected file as the timescale below, in which case the chart is clipped to that file's own span (handy for a short run alongside a continuously-logged file that covers far more than you need). Hover the chart to see the matching position on the map, the map to jump the chart there, or the chart to read exact values + time under it.
